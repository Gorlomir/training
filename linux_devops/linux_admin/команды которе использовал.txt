это виртуальный интерфейс для внутренней коммуникации сервера "сам с собой". Он нужен для работы localhost.
DHCP (протокол динамической конфигурации хоста) — это протокол, который автоматически назначает IP-адрес и другие сетевые параметры этим интерфейсам для работы в сети.
ествия:
1 задал название машины с помощью команды sudo hostnamectl set-hostname user-1 после этого перезагузил для принятия изменений
2 установил временную зону с помощью команды sudo timedatectl set-timezone Asia/Yekaterinburg и проверил с помощью timedatectl
3 с помощью ip link show вывел названия сетевых интерфейсов(io внутренний, enp0s3 внкшний)
4 получил ip от DHCP с помощью команды sudo dhclient -v enp0s3
5 с помощью команд ip route show default и curl ifconfig.me вывел ip и gw
6 для установки вручную открыл с помощью nano файл 00-installer-config.yaml затем отредактировал его
7. перезагрузил и проверил с помощью команды systemd-resolve --status произошли ли изменения
