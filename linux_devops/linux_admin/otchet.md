## PART 3
io -это виртуальный интерфейс для внутренней коммуникации сервера "сам с собой". Он нужен для работы localhost.

DHCP (протокол динамической конфигурации хоста) — это протокол, который автоматически назначает IP-адрес и другие сетевые параметры этим интерфейсам для работы в сети.

Дествия:
1. задал название машины с помощью команды sudo hostnamectl set-hostname user-1 после этого перезагузил для принятия изменений
2. установил временную зону с помощью команды sudo timedatectl set-timezone Asia/Yekaterinburg и проверил с помощью timedatectl
3. с помощью ip link show вывел названия сетевых интерфейсов(io внутренний, enp0s3 внкшний)
4. получил ip от DHCP с помощью команды sudo dhclient -v enp0s3
5. с помощью команд ip route show default и curl ifconfig.me вывел ip и gw
6. для установки вручную открыл с помощью nano файл 00-installer-config.yaml затем отредактировал его
7. перезагрузил и проверил с помощью команды systemd-resolve --status произошли ли изменения

## PART 5
Истинное назначение команды sudo — предоставление временных привилегий суперпользователя (root) для выполнения конкретных команд, что повышает безопасность системы по сравнению с постоянным использованием учетной записи root. Эта команда позволяет пользователям выполнять административные задачи, такие как установка программ, изменение настроек или управление сетевыми интерфейсами, по одной команде, вводя свой собственный пароль вместо пароля.

5. Перезагрузка системы
 использовал команду sudo reboot
Расшифровка -tan
-t показывает только tcp подключения
-а показывает все подклюения, как активные так и ожидающие
-n не преобразовывает имена адресов и хостов в символы, оставляет их в цифрах
Значение вывода
Proto-Протокол соединения.
Recv-Q-объем данных, скопиленных в буфере сокета и еще не прочитанных процессом.
Send-Q-объем данных, отправленных удаленной стороне, но еще не подтвержденных ею.
Local Address	Локальный адрес и порт
Foreign Address	Удаленный адрес и порт. Для слушающих портов это 0.0.0.0:* или :::*, что означает "любой адрес".
State	Текущее состояние TCP-соединения.
0.0.0.0 это специальный адрес, который означает "все доступные сетевые интерфейсы".
